论文元数据来自 arXiv。库内被引是这个库里有多少篇论文的参考文献引用了它；S2 被引来自 Semantic Scholar；stars 来自论文的代码仓库。新论文和这些数字每周自动更新一次。

标题链接到 alphaXiv，博客链接到原文。发表去向取自作者在 arXiv 写的备注。新收录的条目一律是未读，是否相关由关键词规则判断，会混进不相关的论文。
